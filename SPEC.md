# System Specification

## Project

PTC Mask Transfer System.

## Current Control Architecture

- PLC: Mitsubishi FX5U-64MT/ES.
- Motion option under evaluation: FX5-40SSC-S with MR-J4-B servo amplifiers.
- HMI: Pro-face ET6000 series, model PFXET6400WAD.
- Barcode reader under evaluation: KEYENCE SR-1000W.
- Servo axes planned:
  - X traverse.
  - X lift.
  - Z rotation.
  - Z lift.
