# 14_HMI畫面標準

| 畫面/功能 |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- |
| 自動畫面 | 正向啟動 | M6002 -> M1102 | X0000、X0001、M1125/M1225/M1325、M4117/M4317/M4517、Barcode前置OK | Auto Busy、Alarm、Manual Mode | 儲存盒到上機盒；M6001禁用。 |
| 自動畫面 | 反向啟動 | M6003 -> M1103 | 同上 | 同上 | 上機盒到儲存盒。 |
| 自動畫面 | Auto Stop | M6004 | 自動中 |  | 一般停止/暫停，不等同EMO。 |
| 狀態總覽 | Auto Busy/Ready | M1004/M1126/M1226/M6102/M1125/M1225/M1325 | 常時顯示 |  | 顯示機台可啟動條件與目前Step。 |
| 初始化 | 全部初始化 | M1001 -> M13 | 安全OK、氣壓OK | Auto Busy | MAIN先升降再橫移，再Z升降Home；Axis4不進Auto Init。 |
| 初始化 | X橫移初始化 | M1123 | 手動/工程 | Auto Busy | 走S190~S198。 |
| 手動調機 | X橫移JOG-/JOG+ | M6011/M6012 -> M4131/M4132 | M6010+M6200+M6250 | Auto Busy、安全NG、Z未安全 | 速度使用手動速度D。 |
| 手動調機 | X升降JOG-/JOG+ | M6013/M6014 -> M4341/M4340 | M6010+M6200+M6251 | Auto Busy、安全NG | 只使用M4340/M4341；M4331/M4332禁用。 |
| 手動調機 | Z升降JOG-/JOG+ | M6015/M6016 -> M4531/M4532 | M6010+M6200+M6252 | Auto Busy、安全NG、X未Clear | 需避開X/Z干涉。 |
| 手動調機 | Z旋轉0/90/180/270 | M6400 + S400 / M6402~M6405 | M6010+M6200+M6253 | Auto Busy、Z高度不安全、定位氣缸未縮回 | D6412只作建議角度參考，自動禁止。 |
| 手動單動 | 夾爪開/關 | M6210/M6211 -> PLC互鎖 -> Y0007/Y0010 | M6010+M6200+M6251 | Auto Busy或安全NG | HMI不得直寫實體Y。 |
| 手動單動 | X手臂真空ON/破真空 | M6212/M6213 -> PLC互鎖 -> Y0015/Y0016 | 手動模式、位置安全、二次確認 | Auto Busy或安全NG | 取放片材料存在時需二次確認。 |
| 手動單動 | 儲存盒/上機盒真空ON/破真空 | M6214~M6217 -> PLC互鎖 -> Y0017/Y0020/Y0021/Y0022 | 手動模式、盒在席、確認視窗 | Auto Busy或安全NG | 盒體真空不得當作手臂取片真空。 |
| 手動單動 | 檢查站定位伸出/縮回 | M6220~M6223 -> PLC互鎖 -> Y0011~Y0014 | X Clear、Z安全、雙線圈互斥 | Auto Busy或安全NG | Y0011/Y0012、Y0013/Y0014不得同時ON。 |
| Barcode | 生產前掃碼/重掃/NG確認 | D6300/D6350/D6400/D6402/D6420/M6301/M6304/M6305 | 安全OK或Service Unlock流程 | 門未關且未授權服務模式 | Barcode NG需彈窗、重掃一次、確認失敗退回來源。 |
| Reset | 異常復歸 | M6040 | 異常條件解除 | Safety未復歸 | 只清軟體警報。 |
| Reset | 伺服復歸 | M6041 | 安全OK、Servo可復歸 | 軸仍動作中 | 對應伺服/軸卡錯誤復歸。 |
| Reset | 安全復歸 | M6042 -> Y0000瞬時 | EMO釋放、門鎖成立 | 任一安全條件未成立 | 安全繼電器復歸獨立於Alarm Reset。 |
| I/O監看 | X/Y即時狀態 | 所有正式X/Y | 常時 |  | 只顯示正式點位；Deprecated不得出現在正式畫面。 |
| 參數/Recipe | 位置/速度/Tolerance | D4100/D4300/D4504/D4704 + D41xx/D43xx/D45xx/D47xx | 工程權限、軸停止 | Auto Busy | Teach/Save需確認，不直接高頻寫Flash ROM。 |
